# 虹のスライドパズル

幅を自由に決められるスライドパズルです。虹のグラデーションか、好きな画像で遊べます。

## ファイル構成

```
index.html      画面の構造
css/style.css   見た目
js/main.js      ゲームの動き
.nojekyll       GitHub Pages で Jekyll の処理を止めるための空ファイル
```

ビルドは不要です。ブラウザで `index.html` を開くだけでも動きます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`slide-puzzle`）。
2. このフォルダの中身（`index.html`・`css`・`js`・`.nojekyll`・`README.md`）をリポジトリの一番上に置いてコミット・プッシュする。
3. リポジトリの **Settings → Pages** を開く。
4. **Build and deployment** の **Source** で「Deploy from a branch」を選び、ブランチを `main`、フォルダを `/ (root)` にして **Save**。
5. 1〜2分ほどで `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。

## 遊び方

- 開始画面で幅、数字の表示、穴の位置のランダム化、タイマー・手数の表示、絵柄を決めて「開始」。
- 空きマスの隣のマスをタップすると、そのマスが空きマスへ動きます。
- 2本指やマウスホイールで拡大・縮小、拡大中はドラッグで盤面を動かせます。
- タイマーと手数の両方を表示しているときだけ、クリア時にポイントが出ます。

## ポイントの計算

```
基礎点   = 1000 × (幅 × 幅 − 1)
目安手数 = 2.5 × 幅³
目安時間 = max(目安手数 × 0.6, 10) 秒
手数評価 = 2 ÷ (1 + 手数 ÷ 目安手数)
時間評価 = 2 ÷ (1 + 秒数 ÷ 目安時間)
ポイント = 基礎点 × (手数評価 + 時間評価) ÷ 2
```

設定と幅ごとの自己ベストは、そのブラウザの localStorage に保存されます。
